Mapping under-explored chemical space in marine natural products. Structural families from the MarineNP release, crossed against WoRMS-resolved source taxonomy.

How chemical breadth scales with sampling effort

Each point is a genus. Structural families grow as a power of the number of compounds reported, so a genus studied ten times as hard yields far fewer than ten times the families. Points well below the fitted curve are chemically repetitive relative to the work already done.

genus saturated (z < −1.96) fitted curve

The deviations are one-sided

Standardised deviation from the curve. A genus can be far more repetitive than expected, but nothing is far more diverse, because a genus produces biosynthetically related metabolites. No taxon reaches the positive threshold at either genus or order level.

Which genera produce which chemistry

A bipartite network for one taxonomic order at a time. Each genus links to every structural family it produces. The whole matrix is 99% empty, so the network is only legible one order at a time — that sparseness is the finding, not a display problem.

Node area is proportional to compounds for a genus and to members for a family. A family touching one genus in this order sits at the rim; one shared across many is pulled toward the centre.

Saturated genera

Below the curve at z < −1.96. Further screening of these has poor expected return per compound isolated.

The coverage frontier

Orders whose chemistry is broad for the effort spent, counted by how many of their genera remain effectively unexamined. This rests on the order being productive and the genus being unstudied, not on estimating breadth from a handful of compounds.

Provenance: organism records whose identifier resolves elsewhere

The release reconciles organism names to WoRMS by fuzzy matching. These records carry an AphiaID belonging to a different genus, so every property inherited from it — phylum, habitat flags — is wrong.
